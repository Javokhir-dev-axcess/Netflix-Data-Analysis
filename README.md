# Netflix Data Analysis

Simple data analysis and charts on Netflix movies and TV shows using Python (`pandas` and `matplotlib`).

## About the Dataset
`netflix_titles.csv` is not my work. I only added it here for learning and practice. The original dataset belongs to its real creators.

## Charts
- Movies vs TV Shows count
- Top 10 countries creating Netflix content
- Content released after 2000 by year

## Main Findings
- Movies are much more common than TV Shows.
- The United States produces the most titles, followed by countries like India and the UK.
- Content releases grew fast after 2000, with a big jump around 2015–2018.
